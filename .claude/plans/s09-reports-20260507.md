## Key design decisions

- **`ScreenHeader`** (not AppHeader) per spec — `reports/_layout.tsx` already has `headerShown: false`.
- **Single `lib/api/reports.ts`** — all 7 fetchers co-located with shared helpers.
- **`partial: 0`** passed to `CollectionProgressBar` — DB has no partial bill status.
- **Inline `<Text style={{color: colors.warning}}>` ** for amber amounts (AmountText has no warning variant).
- **Route params** for propertyId: menu passes `{ propertyId }` via `router.push` params.
- **`Share.share({ message: csv })`** — no filesystem writes needed.
- **`daysVacant` fallback to `created_at`** — no vacated_at column on units (known limitation).

## Risks

- `OccupancyBarChart` month label format must match — use `dayjs().format('MMM')` consistently.
- AmountText has no 'warning' variant — work around inline for 2 callsites.
- PropertySelector local state in menu doesn't persist — use route params.
- Maintenance data will be empty until s08 screen is wired to `maintenance_issues` table.

## Locked Decisions

- `react-hook-form` + `zod` are the form layer for all screens going forward. Do not use manual `useState` per field in any new form screen.
- `date-fns` replaces all manual date string manipulation.
- `sonner-native` replaces all `Alert.alert()` success/error feedback (destructive confirms keep `Alert`).
- `expo-haptics` added to all Pressable interactions where tactile feedback is appropriate.

## 4.1.1 — `react-hook-form` + `zod`

**Install:**
```bash
npx expo install react-hook-form zod @hookform/resolvers
```

**Purpose:** Centralized form validation across all form screens.

**Existing screens to migrate:**
- `app/(admin)/billing/new.tsx`
- `app/(admin)/tenants/new.tsx`
- `app/(admin)/settings/rates.tsx`

**Pattern to use:**
```ts
import { useForm, Controller } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'
import { z } from 'zod'

const schema = z.object({
  amount: z.number({ required_error: 'Required' }).positive(),
  // ...
})

type FormData = z.infer<typeof schema>

const { control, handleSubmit, formState: { errors } } = useForm<FormData>({
  resolver: zodResolver(schema),
})
```

**Done criteria:**
- [ ] Package installed
- [ ] At least one existing form screen migrated as reference implementation
- [ ] `Input` component in `components/ui/Input.tsx` accepts `error?: string` prop (shows red hint below field)

## 4.1.2 — `date-fns`

**Install:**
```bash
npx expo install date-fns
```

**Purpose:** Eliminate manual date string hacks and timezone edge cases.

**Replaces these patterns:**
```ts
// before
date.toISOString().split('T')[0]
new Date(dateStr + 'T00:00:00')

// after
import { format, parseISO, startOfMonth, endOfMonth, addMonths } from 'date-fns'
format(date, 'yyyy-MM-dd')
parseISO(dateStr)
```

**Done criteria:**

## 4.1.3 — `sonner-native`

**Install:**
```bash
npx expo install sonner-native
```

**Purpose:** Non-blocking toast notifications to replace `Alert.alert()` for success/error feedback.

**Setup:** Add `<Toaster />` to `app/_layout.tsx` once (root layout).

**Usage:**
```ts
import { toast } from 'sonner-native'

toast.success('Payment recorded')
toast.error('Failed to save — check your connection')
```

**Rules:**
- Use `toast.success` / `toast.error` for all save/delete confirmations.
- Keep `Alert.alert` only for destructive confirms (delete, move-out) that require explicit user acknowledgement before proceeding.

**Done criteria:**
- [ ] Package installed
- [ ] `<Toaster />` mounted in root layout
- [ ] At least one screen migrated as reference

## 4.1.4 — `expo-image-picker`

**Install:**
```bash
npx expo install expo-image-picker
```

**Purpose:** Wire up `CameraCapture.tsx` to actually launch camera / photo library.

**Update `CameraCapture.tsx`:**
```ts
import * as ImagePicker from 'expo-image-picker'

const handleCapture = async () => {
  const result = await ImagePicker.launchCameraAsync({
    mediaTypes: ImagePicker.MediaTypeOptions.Images,
    quality: 0.8,
    allowsEditing: true,
  })
  if (!result.canceled) onCapture(result.assets[0].uri)
}
```

Add `expo-image-picker` permissions to `app.json`:
```json
"plugins": [
  ["expo-image-picker", { "cameraPermission": "Allow $(PRODUCT_NAME) to take photos of documents." }]
]
```

**Done criteria:**
- [ ] Package installed
- [ ] `CameraCapture.tsx` actually launches camera on press
- [ ] `onCapture` signature updated to pass URI: `onCapture: (uri: string) => void`

## 4.1.5 — `expo-haptics`

**Install:**
```bash
npx expo install expo-haptics
```

**Purpose:** Tactile feedback on key interactions.

**Usage pattern:**
```ts
import * as Haptics from 'expo-haptics'

// Light: chip selectors, filter tabs, segmented control
Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light)

// Medium: primary action buttons, form submit
Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium)

// Heavy: PIN keypad digits
Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Heavy)
```

**Components to update:**
| Component | Style |
|---|---|
| `PINKeypad.tsx` — digit press | Heavy |
| `PINKeypad.tsx` — backspace | Light |
| `FilterChipBar.tsx` — chip select | Light |
| `SegmentedControl.tsx` — segment select | Light |
| `MonthTabSelector.tsx` — tab select | Light |
| `Button.tsx` — primary press | Medium |

**Done criteria:**
- [ ] Package installed
- [ ] `PINKeypad.tsx` updated (most impactful)
- [ ] `FilterChipBar.tsx` updated
